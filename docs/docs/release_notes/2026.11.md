# Bodo 2026.11 Release (Date: 11/04/2026) {#November_2026}

### 🎉 Highlights

This release, we add support for Python 3.15 and upgrade our Numba, Pandas, and Pyarrow dependencies to the latest versions.

### ✨ New Features
- Added support for Python 3.15
- Added special rendering logic for inlined CTE nodes in plan dumps

### ⚙️ Dependency Updates
- Upgraded to Numba 0.68
- Upgraded to Pandas 3.1
- Upgraded to Pyarrow 26

### 🛠️ Infrastructure
- Pinned Bodo version in BodoSQL package
- Improved robustness of BodoSQL build in Windows environments
